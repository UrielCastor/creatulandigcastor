se realizo un proyecto en react-vite con javascript, un ecomerce de una tienda de hardware funciona actualmente sin usuarios ni contraseñas con un carrito global para toda la web, utilzia un contexto para manejar el carrito, esta dividido en componentes y pages, se trato de dar la responsabilidad correcta a cada componente y cada page, se utiliza firebase para almacenar los productos y las compras
